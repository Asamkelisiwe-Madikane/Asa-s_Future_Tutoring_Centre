# Asa's_Future_Tutoring_Centre
## Website Project

Asa's Future Tutoring Centre is a tutoring-centre website developed to provide learners and parents with information about available tutoring services, subjects, enquiries and contact details.

The website was created as part of a web development project and is designed to demonstrate the use of HTML, CSS, images, navigation, forms and website structure.

---

## 1. Project Overview

Asa's Future Tutoring Centre provides academic support to learners who need assistance with their school subjects.

The website provides information about:

- The tutoring centre
- The centre's mission and vision
- Subjects offered
- Tutoring services
- Online tutoring
- Enquiry and registration information
- Contact details
- Social-media platforms

The main purpose of the website is to make information about the tutoring centre easily accessible to learners and parents.

## 13. Website Images

The website uses images to support the information provided on the Services page.

Each image includes alternative text using the `alt` attribute.

For example:

    <img src="../assets/mathematics.jpg"
         alt="Mathematics tutoring"
         width="300">

The `alt` attribute provides a description of the image and improves accessibility.
